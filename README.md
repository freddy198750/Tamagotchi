# Mochi Garden 🐣

เกมเลี้ยงสัตว์สไตล์ Tamagotchi ที่เล่นผ่านเว็บได้ทันที พัฒนาด้วย HTML, CSS และ JavaScript ภายในไฟล์เดียว

## วิธีเล่น

เปิดเว็บไซต์ GitHub Pages ของโปรเจกต์ หรือดาวน์โหลดไฟล์ `index.html` แล้วเปิดด้วยเบราว์เซอร์

- ตั้งชื่อและเลือกสีสัตว์เลี้ยง
- ให้อาหาร อาบน้ำ เล่น และพาเข้านอน
- สะสมเหรียญ ซื้อของ และเล่นมินิเกมจับดาว
- เพิ่มเลเวลและเลี้ยงสัตว์ให้เติบโต

## การบันทึกเกม

เกมใช้ `localStorage` ของเบราว์เซอร์ในการเก็บข้อมูลอัตโนมัติ **ยังไม่มีระบบบัญชีหรือฐานข้อมูลออนไลน์** ข้อมูลอาจหายเมื่อเคลียร์ข้อมูลเว็บไซต์หรือย้ายอุปกรณ์

## เปิด GitHub Pages

เข้า **Settings → Pages → Build and deployment → Deploy from a branch** เลือก **main** และ **/(root)** แล้วกด **Save**

เมื่อเปิดใช้แล้ว คาดว่า URL เกมคือ https://freddy198750.github.io/Tamagotchi/
